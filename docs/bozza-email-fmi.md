**Oggetto:** Terms of use — republishing WEO statistical data on a non-commercial educational website

Dear IMF Data team,

I am a finance student and I am building a small, free, non-commercial educational dashboard of macroeconomic data
(a static website published on GitHub Pages, with no advertising and no paid content). I would like to display a selection of
World Economic Outlook (WEO) series — real GDP growth, nominal GDP, GDP per capita (PPP), inflation, general government balance and gross debt,
current account balance and population — for individual countries, together with the WEO projections, in charts and tables.

My understanding of the IMF Copyright and Usage page is that published statistical data may be copied, used in derivative works and republished with attribution.
Could you please confirm that this applies to my use? In particular:

1. Is it acceptable to display WEO series (all countries, annual, 1980 to the projection horizon) in charts and tables on the website, with a visible citation

2. I would keep a copy of the data in a public code repository (CSV files, updated only at each new WEO release, i.e. twice a year).
   Is a public copy of the WEO data in a repository acceptable under the same conditions?
3. To build that copy I would query the SDMX API at api.imf.org with about 12 requests (one per indicator, all countries), run manually by me twice a year, never on an automatic schedule.
   Is this acceptable, or would you prefer that I download the WEO files from the website instead?
4. Is there any specific attribution wording you would like me to use, or any series that I should not republish?
